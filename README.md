## 🎬 About ZynAds

**ZynAds** is an AI-powered commercial production suite and virtual teleprompter studio. It enables creators, video marketers, and founders to direct, record, and produce 4K-style commercial videos complete with:

- **AI Scene & Prop Synthesizer**: Custom virtual background sets (Motherboard Pasture, Cyberpunk Stage, Executive Loft) and interactive props.
- **Real-Time Voice Dictation**: Hands-free voice typing and AI script transcription powered by Gemini 2.5 Flash.
- **Live 4K Virtual Broadcast Teleprompter**: Studio canvas with presenter overlay, lower-third banners, call-to-action overlays, and canvas video recording.
- **Campaign Workspace**: Ad performance metrics, ROAS tracking, target audience management, and CFO financial insights.

## 🚀 Quick Start in GitHub Codespaces

1. Click the **Open in GitHub Codespaces** button above or navigate to [`https://codespaces.new/coffeehart-lang/zynads`](https://codespaces.new/coffeehart-lang/zynads).
2. Codespaces will automatically configure Node.js 22 and run `npm install`.
3. Start the application:
   ```bash
   npm run dev
   ```
4. Access the web application on port `3000`.

---

## 🛠️ Local Installation

```bash
# Clone the repository
git clone git@github.com:coffeehart-lang/zynads.git
cd zynads

# Install dependencies
npm install

# Start development server
npm run dev
```

---

## ⚙️ Environment Variables

Copy `.env.example` to `.env`:

```env
GEMINI_API_KEY="your-gemini-api-key"
APP_URL="http://localhost:3000"
```
